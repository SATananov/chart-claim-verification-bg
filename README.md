# Chart Claim Verification

This project studies whether a neural network can compare a statistical chart with a short text claim.

The result will be one of three classes:

- supported
- refuted
- not enough information

## Main question

Can a model that uses both chart images and text perform better than models that use only one type of input?

## Planned work

1. Understand and clean the data
2. Generate simple chart images
3. Generate short claims
4. Create train, validation and test sets
5. Build simple baseline models
6. Build a Keras text model
7. Build a Keras CNN
8. Combine the text and image models
9. Evaluate the results
10. Write the final conclusions

## Current status

The project structure and notebook plan are ready. Data preparation and experiments are not completed yet.
