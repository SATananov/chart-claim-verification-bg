# Project plan

## Problem

A chart can contain correct data while a short statement beside it describes the data incorrectly.

The project will compare a chart image with a short claim and predict one of three labels:

- supported
- refuted
- not enough information

## Planned notebooks

| Notebook | Main work |
|---|---|
| 00 | Problem definition |
| 01 | Data understanding and cleaning |
| 02 | Chart generation |
| 03 | Claim generation |
| 04 | Train, validation and test split |
| 05 | Simple baselines |
| 06 | Text model with Keras |
| 07 | Image model with Keras |
| 08 | Multimodal model |
| 09 | Evaluation and error analysis |
| 10 | Final results and conclusions |

## Important rule

Results, observations and conclusions must be added only after the experiments are run.
