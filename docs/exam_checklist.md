# Exam checklist

- [ ] The problem is clearly defined
- [ ] The project explains why the problem is useful
- [ ] The notebooks are ordered and readable
- [ ] The code is divided into simple functions
- [ ] At least two research sources are cited
- [ ] Data gathering and cleaning are documented
- [ ] Train, validation and test sets are separate
- [ ] Simple baselines are compared with neural models
- [ ] Tests are included
- [ ] Visualizations are clear
- [ ] Results and limitations are explained honestly
